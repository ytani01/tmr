# wording 報告（TODO.md の推敲）

対象: `TODO.md`。日本語の書き方だけを直した。項目の中身・判断・番号・
チェックボックス・表・リンク・完了済みの目次には手を付けていない。

## 直した箇所

### 1. TODO-012 の背景（旧 22 行目）

- 直す前: どちらも TODO-010 より前から同じで、分割で持ち込んだものではない
- 直した後: どちらも TODO-010 より前からあり、分割で持ち込んだものではない

理由: 「前から同じで」は何が同じなのかが読み取れない。前から存在していた、
という意味に読める形へ直した。

### 2. 補足（旧 79〜80 行目）

- 直す前: この運用を始める前の過去の記録。
- 直した後: この運用を始める前の記録。

理由: 「始める前の」と「過去の」が同じことの繰り返し。

### 3. TODO-013 の見出し（指摘を受けて main が直した）

- 直す前: `t_limit` が `ProgressBar` に焼き付いている
- 直した後: `ProgressBar` が古い `t_limit` を持ち続ける

理由: 「焼き付いている」が一般的でない言い回しのため。wording の
「気になった箇所」を受けて main が直したので、wording 側では手を
入れていない（本文の「両者がずれると」→「両者が食い違うと」も同じ）。
