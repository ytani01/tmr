# TODO-007 の分担

| 担当 | モデル | 役割 |
|------|--------|------|
| main | Opus 5 / effort high | 実装（`setattr()` への書き換え、`test_dummy.py` の削除） |
| verifier | Haiku 4.5 | 完了条件の確認 |

## この分担にした理由

- 変えるのはテストコード 2 箇所と 1 ファイルの削除だけで、**実装の担当を
  分けるほどの規模ではない**（複数ファイルにまたがらず、テストと文書が
  まとまって要るわけでもない）。main が実装した
- ただし**コードを変える項目なので、確認は必ず別の担当に分ける**規約に
  従って verifier を立てた。実装した本人は「動くはず」で済ませてしまう
- **reviewer は付けなかった。** 挙動も分岐も条件式も変わらず、
  `setattr(obj, "__str__", x)` は `obj.__str__ = x` と実行時には同じで、
  静的解析の見え方だけが変わる。「良いか」を見る余地が無い
- 確認の内容は決まった 5 つのコマンドを流して結果を照合するだけなので、
  判断の要らない担当として Haiku（定義のまま）で足りると見た
