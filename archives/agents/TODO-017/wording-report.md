### 2. README.md 203-205 行目（docs/User.md、アラーム冒頭） — 括弧の入れ子で読みにくい

現在:

```
タイマーが満了すると、ベル文字（`\a`）を鳴らします。
実際に音が出るかは端末の設定によります
（`--alarm-cmd` を指定すると、代わりに任意のコマンドを実行します。後述）。
```

直す文:

```
タイマーが満了すると、ベル文字（`\a`）を鳴らします。

`--alarm-cmd` を指定すると、代わりに任意のコマンドを実行します（後述）。

理由: 「端末の設定による」という話と「`--alarm-cmd` の話は後述」という話が
1 つの括弧に同居していて、閉じ括弧まで読まないと意味が取れない。
文を分けて、後述の注記だけ短い括弧にする。

### 4. docs/User.md 106-107 行目 — 「サイクル」と「巡」が同じ文に出て紛らわしい

現在:

```
- サイクルは `[Q]` を押すまで**何巡でも続きます**。
  `-c` は「長い休憩までの作業回数」であって、全体の回数ではありません。

```

### 5. docs/Developer.md 92-94 行目 — 「巡回」が他の文書と揃っていない

現在:

```
`phases()` はジェネレータで、**フェーズを無限に返します**。
`cycles` は「長い休憩までの作業回数」という 1 巡の長さで、
巡回そのものは終わりません。終わらせるのは `run()` 側の判断です。
```

直す文（該当部分のみ）:

```
`cycles` は「長い休憩までの作業回数」という 1 巡の長さで、
**何巡でも続き、繰り返しそのものは終わりません**。終わらせるのは

用語がそろっていない。「巡回」は警備の見回りのような語感もあり、
ここでは「繰り返し」で足りる。
